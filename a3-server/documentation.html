Media API Documentation

Base URL: http://localhost:3000

1. List All Media

GET /media

Retrieves a list of all media items ordered by year (descending).

Success Response

  • Code: 200 OK
  • Content: Array of Media Objects

Error Response

  • Code: 404 NOT FOUND
  • Message: Media item not found

2. Get Specific Media

GET /media/:id

Retrieves details for a single media item by its unique ID.

Path Parameters

ParameterTypeDescription
idNumberThe unique id of the media item.

Success Respons

  • Code: 200 OK
  • Content: single media object

Error Responses

  • 400 Bad Request: ID is not a number.
  • 404 Not Found: Item does not exist.

3. Create Media Item

POST /media

Adds a new item to the database.

Request Body (JSON)

{
  "name": "Inception",
  "year": 2010,
  "genre": "Sci-Fi",
  "poster": "url_to_image",
  "description": "A thief who steals corporate secrets..."
}
  • Code: 201 Created
  • Content:
{
  "id: 1"  
  "name": "Inception",
  "year": 2010,
  "genre": "Sci-Fi",
  "poster": "url_to_image",
  "description": "A thief who steals corporate secrets..."
}

Error Response

  • 400 Bad Request: Missing required fields

4. Update Media Item

PUT /media/:id

All fields must be filled in

Success Response

  • Code: 200 OK

Error Responses

  • 400 Bad Request: ID is not a number
  • 404 Not Found: Media not found

5. Delete Media Item

DELETE /media/:id

Removes a media item from the database permanently.

Success Response

  • Code: 204 No Content

Error Responses

  • 400 Bad Request: ID is not a number
  • 404 Not Found: Media not found
